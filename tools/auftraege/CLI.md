(mit ^ unter der Fehlerstelle), "% Incomplete command.", "% Ambiguous command:  \"…\"", im Exec-Modus bei Unbekanntem "Translating \"xyz\"...domain server (255.255.255.255)" + "% Unknown command or computer name, or unable to find computer address" (belege das Format oder vereinfache).

Deutsche Windows-Texte, soweit belegbar; sonst schlicht und markiert.
- Ausgaben an echten IOS-Formaten orientieren (show ip interface brief: Spalten Interface / IP-Address / OK? / Method / Status / Protocol, „administratively down“; show vlan brief inkl. 1002–1005; show mac address-table; show ip route mit Codes C/L/S/S* und „Gateway of last resort“; L-Routen /32 wie ab IOS 15). Belege die Formate per WebSearch/WebFetch in Cisco-Dokumentation, wo du unsicher bist, und nenne die Quellen im Bericht.
- Eine Quelle der Wahrheit: jede Änderung über Modell.setzen/Modell.loeschen/Modell.vlan/Modell.speichern/Modell.neustart/Modell.startupLoeschen. Änderungen gelten sofort (running). CLI.sitzung(netz, id, {verlauf, einstieg}): wenn ein Modell.verlauf übergeben wird, JEDE ändernde Zeile über verlauf.aendern("Konsole: <befehl>", …) ausführen (Rückgängig gilt dann auch für Konsolenbefehle).
- CLI.runningConfig(geraet) in IOS-Reihenfolge (version/hostname/enable secret/ip dhcp excluded-address/ip dhcp pool/interfaces/ip nat/ip route/access-list/banner/line/end). Switch: VLANs NICHT in der running-config (VTP-Server-Modus, liegen in vlan.dat) – belege oder markiere. CLI.entspricht(geraet, pfad, wert) liefert für jede GUI-Änderung den passenden Befehlsblock (für die „entspricht:“-Zeile im Inspektor), z. B. pfad "if.Gi0/0.ip" → "interface GigabitEthernet0/0\n ip address 10.0.0.1 255.255.255.0" (Maske aus der aktuellen Konfig), "ports.Fa0/5.accessVlan" → "interface FastEthernet0/5\n switchport access vlan 20", Host-Pfade → Windows-Befehl (netsh interface ip set address …) oder null. CLI.anwenden(netz, id, text) führt einen mehrzeiligen Block aus (ab privilegiertem Modus; „conf t“/„end“ dürfen im Text stehen; Rückfragen automatisch bestätigen) und liefert {ok, fehler:[{zeile, meldung}]}. CLI.vorschlag(sitzung) für den Einstieg (nächster sinnvoller Befehl je Modus/Lage, oder null).
- Portnamen: kanonisch im Modell „Fa0/1“, „Gi0/0“, „Gi0/0.10“; in der Konsole FastEthernet0/1 / GigabitEthernet0/0 mit allen üblichen Abkürzungen (f0/1, fa0/1, fast 0/1, g0/0, gi0/0, gig0/0, GigabitEthernet 0/0 …).
- Fehler erklären, nicht schimpfen: zusätzlich zum IOS-Fehler eine Zeile „Tipp: …“, aber nur wenn sitzung.einstieg === true.
